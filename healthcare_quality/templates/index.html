ONE PROJECT / FIVE DELIBERATE VERSIONS

From rules to an AI-assisted lab.

Each version has a purpose, observable outcomes, acceptance criteria, and its own detailed report.

01

Reliable foundation V1 PRESERVED

Written synthetic contracts, a local claims explorer, Python rules, pytest unit/API checks, Chromium E2E tests, defect experiments, and an optional Ollama review exercise. Understand why each test exists.

02

Healthcare workflows V2 PRESERVED

Persistent synthetic claims, member ownership, duplicate protection, submitted/approved/paid transitions, simulated ledger, atomic history, reusable API clients and page objects, isolated test databases and expanded evidence.

03

AI-generated test proposals V3 PRESERVED

Local Ollama generates new declarative cases. Schema/source/duplicate checks, editable expectations, explicit reviewer attestation, revision-bound approvals and isolated permitted-action execution are now implemented.

04

AI quality & investigation V4 PRESERVED

Introduce a reviewed evaluation dataset, prompt comparisons, source retrieval, failure explanations, uncertainty, and metrics for corrections and meaningful defect detection.

05

Release & professional showcase

Extend the CI baseline into versioned release packaging and deployment for a chosen target. Add resilience, end-to-end evidence, a guided demonstration, and a final architecture report.

LEARN THE TOOLS, EVALUATE THE OUTPUT

AI has a role at every stage.

Codex builds and explains. Ollama can review contracts locally. The project includes exercises for ChatGPT, Copilot, and Claude Code. Their output must be checked against requirements and observed behavior; the number of tools is not a quality metric.
