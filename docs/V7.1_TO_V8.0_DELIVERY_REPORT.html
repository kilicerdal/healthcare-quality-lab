How it was built

The implementation reuses the bounded declarative case language and independent lifecycle oracle. Generated Python is never executed. The production application uses SQLite and its pricing implementation; the reference calculator uses separate Fraction-based pricing. A model may design bounded inputs, but it never grants review or execution authority. The new optional AI planner returns inputs only, then the calculator constructs full expected observations. Quality gates require financial readbacks and reject duplicate business-input signatures in the recent proposal view.

A separate raw-expectation experiment asks models to supply the expected observations once. These original answers are checked without feedback, repairs or replacement. The experiment ledger records exposure, provider/model settings and digests, prompts, source/contract/cohort fingerprints, raw responses, token/runtime metadata, cancellation and interruption. Calculator controls are labeled zero-inference construction, not model accuracy.

The new team ledger binds routing to case content, revision, source and contract. A ready-for-review label does not approve. Authenticated shared-mode users retain the existing role and CSRF boundaries; default loopback mode explicitly uses teaching attestations. The evidence assistant describes saved facts and issues with citations. Its deterministic findings are distinguished from the separate Ollama planner and the existing optional AI investigation tools.

Problems found and corrected

Initial validation exposed a Flask endpoint naming collision, a missing schema definition in the reference-peer endpoint, a missing route parameter, and the report route's missing/new heading contract. These were corrected rather than bypassing tests. The first Mac Firefox attempt could not launch its profile; Linux executed the complete Firefox suite. A recording selector failed on an icon-prefixed accessible name and was replaced by a stable navigation selector, with a workbench round-trip browser assertion. Final review also added duplicate-aware AI export, safe inspection of invalid saved proposals, symlink evidence rejection and one source fingerprint calculation per queue view. Remaining limits

The synthetic packs share invented cost sharing and omit actual Medicare phases and policy documents. Their 37 pack scenarios and the 31 evaluation inputs overlap; counts must not be added as unique coverage. Neither the packs nor the passing HTTP journeys establish every service/policy combination. The second HTTP target shares the oracle used for expected values, so its agreement is an integration control rather than independent proof of the oracle. Queue/deduplication views are bounded to 50 recent proposals. Shared-lab authentication is not enterprise identity or a compliance certification. Advisory lookup and bounded load are not penetration testing or a production capacity guarantee. Raw AI reliability remains unresolved and is visible in the evidence.
