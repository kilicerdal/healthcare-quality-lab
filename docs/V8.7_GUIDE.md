## Evidence interpretation

Model digest/settings and exact raw prompts/responses are in each trial file. The dashboard seals the assembled payload with a content hash. Hashes detect accidental changes, not authorship or cryptographic identity. Source commits and Git history provide additional traceability. Observed latency is not a controlled speed comparison. The tiny synthetic cohort is not real-policy certification, broad qualification or independent human review.
