## Build a dashboard from frozen evidence

```sh
.venv/bin/python -m tools.reliability_showcase --build artifacts/v8.7/study
```

This explicitly checks raw-file integrity, re-evaluates frozen answers, executes disposable HTTP journeys and scores trusted pricing mutations. It makes zero model calls. It requires current-source evidence; historical source is labeled stale when viewed, not silently rescored as current. Failed and incomplete AI cases stay blocked and receive no mutation credit. Reference-authored tests have separate attribution.

## Evidence interpretation

Model digest/settings and exact raw prompts/responses are in each trial file. The dashboard seals the assembled payload with a content hash. Hashes detect accidental changes, not authorship or cryptographic identity. Source commits and Git history provide additional traceability. Observed latency is not a controlled speed comparison. The tiny synthetic cohort is not real-policy certification, broad qualification or independent human review.
