# Lesson 4 — Evaluate an AI-created test

1. Open the V4 AI Quality Lab at http://127.0.0.1:8894/#evaluation.
2. Select the saved development comparison. Read the denominators before judging a score.
3. Find D02. Calculate max(7600 − 10000, 0) yourself. Compare zero with the model's 6600 expectation.
4. Find H03 in the reserved comparison. Explain how correct status assertions can miss an incorrect ledger.
5. Open artifacts/v4/assertion-sensitivity.json in VS Code. Compare 0/2 detection with 2/2 after strengthening assertions.
6. Inspect the investigation record: distinguish the observed assertion from the model's contradictory prose and weak citations.
7. If you choose to fix a generated draft, use AI Test Studio, write a review note, save the edit, review again and execute the approved snapshot. Comparison does not approve cases for you.
8. Optional: use your preferred second assistant to critique the draft. Independently verify its suggestion before approving anything.

A passing test is evidence of its asserted observations, not every property of the application. A reference comparison is evidence about this rubric, not a certification of all possible tests.
