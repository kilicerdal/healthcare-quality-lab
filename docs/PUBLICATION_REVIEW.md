# Public portfolio publication review

Reviewed on **November 17, 2026**, before changing repository visibility.

## What was reviewed

- The 22-commit local history matched GitHub main at `edf1614d1bd060d8eee7c7b55f250be1135e82c3` before the publication changes.
- Gitleaks scanned that history (about 26.77 MB). Its 100 findings were manually classified: 99 SHA-256 file checksums and one recorded UUID operation lease ID. The latter is generated by `uuid4().hex` in [operations.py](../healthcare_quality/operations.py), not an API credential.
- Tracked filenames contained no environment files, private keys, credential files, resume, or SQLite database. The text scan found no email addresses.
- Demo data and recorded model experiments describe invented plans, identities and payments. Tracked screenshot contact sheets and the selected showcase screenshots were inspected. No employer source or real patient records were identified in this review.
- The server binds to `127.0.0.1`. Demo actor headers and reviewer labels are not production authentication. Publishing source does not deploy a public runtime.

These checks reduce publication risk; they are not a guarantee that automated scanning can identify every secret or every sensitive fact.

## Verification

A clean source snapshot with the patched pins passed `python -m tools.verify`:

- **622/622 tests passed**, zero failures or skips: 510 unit, 70 API, 42 actual Chromium checks.
- **7/7 evaluator fault seeds** and **5/5 workflow fault seeds** detected by the authored framework checks. These are separate from the reviewed AI-derived twelve-seed campaign.
- Python 3.13.18, Flask 3.1.3, pytest 9.0.3, Playwright 1.56.0, Waitress 3.0.2.
- Implementation fingerprint: `497f3fd4116fa987eb678850facb9d3aebb8cd38a4fe9b95495316677e7a9111`.

The initial isolated attempt lacked the Chromium path and failed at browser setup; it was not accepted as passing evidence. After configuring the existing browser installation, the unchanged baseline passed, followed by a complete passing run with the patched dependencies.

The patched source package built and passed checksum inspection. Its staged Waitress runtime passed an actual loopback HTTP journey: readiness, payout, submission, duplicate rejection, ownership rejection, approval-before-payment, ledger/history and invalid generation rejection without inference. The rehearsal made zero live model calls. Fresh hosted checks can be inspected in the [Actions tab](https://github.com/kilicerdal/healthcare-quality-lab/actions) after the publication commit.

The historical V5.7 AI measurements and screenshots are retained as dated experiment evidence. No new model inference, OpenAI API call, paid service or public application deployment was part of this review.
