# Healthcare Quality Lab V7.0 reviewer guide

All work belongs to the standalone Healthcare Quality Lab. Rules, identities and money are synthetic. This guide makes no production Medicare, eligibility, payment or compliance claim.

## Start from a fresh checkout

```sh
python3 -m tools.launch_demo --state-dir .local/v7-fresh --port 8897
```

Open `http://127.0.0.1:8897/#journey`. Choose a different fresh directory or unused port if needed. The launcher refuses nonempty state and never resets existing projects. It installs runtime dependencies in this project's `.venv`; it does not download a model or request inference.

The demo seeds explicitly labeled authored controls and replays historical model evidence. Old source fingerprints remain old. A replay is not a new model run or human review.

## Demonstrate the connected engineering argument

1. Inspect the two V6.8 test-design modes. AI expectations measure first-attempt reasoning; calculator-backed generation uses AI for scenario design and the independent calculator for expected values. Both require separate review.
2. Load the authored review control from the guided page. Inspect 71200-cent initial payout, 31200-cent adjustment, history, accounts and zero reversed ledger. It is deliberately authored, not attributed to AI.
3. Enter a meaningful inspection note, approve that snapshot and execute through HTTP. Execution uses fresh synthetic stores. Changing source, contract or case content invalidates the approval.
4. Refresh requirement links and preview BN-004 impact. Derived dependencies differ from model citations. What-if analysis edits no policy and grants no approval.
5. Run the known-defect investigation. The child process demonstrates healthy, one-cent faulty and restored pricing. Read expected 71200 versus observed 71201, request/response evidence and deterministic category. Request an AI explanation only if you explicitly want a local call. Valid citations do not prove every hypothesis.
6. Read the saved effectiveness experiment. The original authored suite detected 25/27 variants; two authored gap controls bring their union to 27/27. Historical AI with calculator values detected 19/27. Wrong raw AI has no score because it failed its healthy baseline. Property controls detected 14/27; survivors remain visible.
7. Inspect the historical frozen comparison. Four raw answers on one XP-03 input were ineligible. Calculator rows make no model call and are not AI reasoning. Do not describe the prompt change as a demonstrated raw-accuracy improvement.
8. Read all six reports, exact source/test receipts and GitHub Actions. Standard and all-browser totals overlap.

```sh
python3 -m tools.bootstrap --browser

.venv/bin/python -m tools.effectiveness --output .local/my-effectiveness.json

```

For the complete browser sweep after installing the matching browsers:

```sh
.venv/bin/python -m playwright install chromium firefox webkit
.venv/bin/python -m pytest tests/unit tests/api tests/e2e --browser chromium --browser firefox --browser webkit -q
```

On Linux, browser system dependencies may also be needed; the CI workflow installs them in an isolated runner. The release receipts identify the actually tested Python/browser versions. Models are not required for ordinary regression.

## Request real local AI explicitly

Ollama must already be running on `127.0.0.1:11434` with a model on the project allowlist. Nothing pulls a model or falls back to a cloud provider.

```sh
.venv/bin/python -m tools.experiments --models qwen2.5-coder:3b qwen3.5:27b --prompts baseline-v67 focused-v68 --tasks XP-03 --repeats 1 --output .local/my-model-comparison.json
.venv/bin/python -m tools.investigate --model qwen2.5-coder:3b --output .local/my-ai-investigation.json
```

The frozen comparison above makes four actual model requests plus separately labeled calculator rows. It reuses an already exposed XP-03 input; it is not a new unseen holdout. The API caps total rows at 24 and repeats at three. New outputs cannot silently overwrite existing files. Interrupted experiments preserve completed responses and exposure history; exporting an existing record makes no new inference.

The V6.5 ephemeral runner remains an opt-in owner-only route for the older advanced evaluation cohort. Its previous real execution is retained as historical evidence; do not relabel it as a V6.12 remote experiment. Hosted V7 regression uses offline provider controls and makes no paid API call.

## Interview discussion

Explain why an internally consistent AI answer can still change the requested scenario, why a wrong baseline earns no mutation credit, why compiler-generated expectations are not model reasoning, and why a matching fact citation is not proof of a root cause. Then show source-bound review, actual HTTP evidence, failed raw answers and finite survivors. Those distinctions are the project's engineering value.
