## Explicit staged inference

V8.4 records pricing first, then makes a separate lifecycle/ledger call containing only the model's own unverified pricing. Both responses are retained. An invalid stage is not repaired. Evaluation happens after generation, with no reference feedback passed into either stage.

Select a scenario, model and time budget, then Estimate. Each whole-case prediction now costs two requests. Optional self-review costs two more. Stepwise prediction costs two requests per step. The maximum remains 24 requests and 300 admitted job seconds. Preflight is separate; backend cancellation is best effort. Do not start another backend experiment merely because an interrupted HTTP caller returned.

```sh
.venv/bin/python -m tools.expectations_v84 --models qwen2.5-coder:3b --tasks D83-01 --max-seconds 60 --state .local/my-v84.sqlite --output artifacts/v8.4/my-v84.json --dry-run
```

Dry-run creates no experiment or model call. Use a fresh output path and remove `--dry-run` only for intentional inference. Wrong values remain blocked. Current-source eligible export creates an unapproved proposal; review and actual HTTP execution remain separate actions.

D83-01 is the exposed original failed pilot. H84-01 and H84-02 were new input variants before this version's recorded evaluation and are exposed now. Do not describe future reruns of these published inputs as blind qualification. Two new numeric variants cannot establish general reliability.

## Coverage evidence download

Use Export coverage evidence JSON after selecting or scoring a saved record. The browser requests `/api/coverage/records/<id>/download`; the server returns an authenticated JSON attachment. It does not generate Blob URLs, call a model or execute a test. The file contains the same record as the read endpoint, including current-source/approval validity markers. Shared authentication and existing coverage roles still apply. Responses are private/no-store.

## Evidence boundaries

Read the detailed V8.4 report and raw files together. Offline provider fixtures establish engineering behavior, not AI accuracy. Failed, interrupted and unattempted trials remain visible. Calculators independently score frozen outputs; they do not fill or fix model values. Earlier artifacts are never overwritten.

## Resumed pilot evidence

The recorded successful case is a manual engineering continuation, not a first-attempt pass or a browser auto-resume feature. Read `confirmation-plan.json`, `continuation-plan.json`, `resumed-revalidation.json` and `resumed-http-execution.json` together. Pricing was reused exactly from a frozen response; lifecycle was explicitly retried once. Protocol version 2 removes only unused exact duplicate quote aliases and changes no expected value. Wrong/missing/conflicting aliases remain rejected. Source identities before generation and after normalization are both retained. The original interrupted experiments remain blocked.

On this machine the recorded large-model pricing response took about 128.8 seconds and the successful lifecycle continuation about 85.7 seconds. Two stages can exceed the default 180-second budget; choosing up to 300 seconds is an explicit operator decision, not an automatic extension or completion guarantee. Splitting the problem did not prove faster inference.
