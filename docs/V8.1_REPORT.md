## What is being built and why

An expectations-only schema prevents input rewriting. Models supply numeric worksheets and complete financial/lifecycle observations. Stepwise prediction receives only prior model predictions. One optional blind self-review receives original model text and applicable rules, never evaluator results. Independent evaluation occurs after both answers are frozen. Durable jobs retain raw answers, exposure, budgets, interruption and cancellation.

## Predeclared acceptance target

At least 80 percent strict first-attempt correctness on ten unique fresh reserved inputs per model, including failed requests in denominators. Self-review is scored separately. The predictor remains experimental if this target is missed. Immutable server assembly is an interface guarantee, not improved model input-following skill.
